# 💖 Romantic Surprise - Telegram Mini App

Интерактивное романтическое веб-приложение и **Telegram Mini App** (аналог сервиса Celamur) для незабываемого поздравления и организации свидания.

![Platform](https://img.shields.io/badge/Platform-Telegram_Mini_App-blue)
![Stack](https://img.shields.io/badge/Stack-Vanilla_JS_%7C_Canvas_2D_%7C_Python-pink)

---

## ✨ Возможности

1. 🔒 **Секретный вопрос (пароль)** — вход только по правильному слову с анимацией проверки.
2. 💌 **Интерактивный сургучный конверт** — 3D-анимация вскрытия печати и выезда письма.
3. 📜 **Письмо + Polaroid-фото** — душевный текст с фотокарточкой и реакциями.
4. 🎡 **Выбор свидания («Что будем делать?»)** — интерактивные карточки с неоновой подсветкой и эффектами.
5. 📅 **Выбор даты и времени** — элегантный барабан выбора дня и времени встречи.
6. 🎨 **Портрет из слов (Word Art / ASCII)** — фото девушки в реальном времени собирается на Canvas из повторяющегося имени (например, `ДАША`), синхронно со счётчиком (*«по 1450 раз думаю о тебе каждый день»*).
7. ✈️ **Отправка результата в Telegram** — нативная интеграция с `Telegram.WebApp.sendData()`, вибрацией и отправкой готового плана свидания парню.
8. 🎵 **Романтическая музыка** — синтезатор нежных арпеджио на Web Audio API.

## 🚀 Быстрый запуск

### 1. Локальный просмотр
```bash
python server.py
```
Сервер автоматически откроет страницу в браузере по адресу `http://localhost:8080`.

### 2. Запуск Telegram-бота
```bash
python bot.py
```
*(Создайте бота через @BotFather и укажите токен в файле `.env`)*

## ⚙️ Настройка контента

Все тексты, имена, даты, варианты свиданий и ссылки на фото настраиваются в одном файле:
👉 **`config.js`**

## 🌐 Деплой на GitHub Pages (Бесплатно)

1. В репозитории перейдите в **Settings** -> **Pages**.
2. В разделе **Branch** выберите `main` и папку `/(root)`.
3. Нажмите **Save**. Через 1 минуту приложение будет доступно по адресу:
   `https://mohangg812.github.io/surprise-app/`
4. Эту ссылку можно вставить в @BotFather для Telegram Mini App!

Подробная инструкция по запуску и настройке бота находится в файле [DEPLOY_GUIDE.md](DEPLOY_GUIDE.md).
